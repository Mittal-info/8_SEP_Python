function : function is a block of code that code we can use again and again

           function which is mainly use to reduce our code.

           function provide reusability.
        
           using of function we can save our time.

           in python there are two types of function

   1) Built in function:

       which is predefined by python. e.g: print(),input(),len()....

   2) User defined function:

       user create function as per requirement

       there are 2 steps to create user defined function

          step:1) function defination

          syntax: def <function name> ():
                    block of code

          step:2) function calling

          syntax: <function name> ():

function categories:

   four types of function categories:

   1)function without parameter and function  without return type
   2)function with parameter and function  without return type
   3)function with parameter and function  with return type
   4)function without parameter and function  with return type
